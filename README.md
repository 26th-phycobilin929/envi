# ⚙️ envi - Manage environment files with ease

[![Download for Windows](https://img.shields.io/badge/Download-Latest_Release-blue.svg)](https://github.com/26th-phycobilin929/envi/releases)

Envi helps you organize your environment files. These files hold secret keys and settings for your software projects. Managing them manually creates mistakes. Envi provides a clear interface to view, compare, and fix these files. You save time and reduce errors in your projects. 

## 📥 How to download the software

Follow these steps to get envi on your Windows computer:

1. Visit the [official releases page](https://github.com/26th-phycobilin929/envi/releases).
2. Look for the section titled "Assets" under the most recent version.
3. Click the file ending in `.exe` that matches your system.
4. Save the file to your computer.
5. Double-click the file to open the program.

## 💻 System requirements

Envi runs on modern versions of Windows. Ensure your system meets these standards:

- Windows 10 or Windows 11.
- At least 4GB of RAM.
- A stable internet connection for updates.
- Basic familiarity with your folder structure.

## 🚀 Setting up your environment

Once you open the software, follow these steps to connect your folders:

1. Click the "Add Project" button in the menu.
2. Select the folder containing your project files.
3. Envi scans your directories for any `.env` files.
4. The list displays your variables on the screen.

## ✨ Core features

Envi keeps your files organized. Use these tools to maintain your settings:

- **Compare files:** See differences between two environment files side-by-side. Use this to find missing keys that cause bugs.
- **Scan errors:** The program checks for typos and missing values. It alerts you before you save a broken file.
- **Edit values:** Change your settings directly inside the program. Hit save and the application updates the file for you.
- **Switch profiles:** Keep different settings for work, testing, and production. Switch between them with one click.
- **Validate types:** Ensure your values follow the correct format. This prevents crashes in your software.

## 🔍 Understanding the interface

The dashboard shows a simple table. Each row represents a variable name and its assigned value. 

- **Left Column:** Displays the variable names.
- **Middle Column:** Shows the current values stored in your file.
- **Right Column:** Contains status indicators. A green checkmark means the value is valid. A red alert means the value needs attention.

Use the search bar at the top to find specific keys quickly. This helps if your project holds hundreds of settings.

## 🛡️ Maintain security

Your environment files contain sensitive data. Envi treats these files with care. The software only reads and writes to the locations you select. It does not send your data to external servers. All operations happen on your local machine.

## 🛠️ Resolving common issues

If the software does not open:

1. Check your antivirus settings. Some security programs block new software. Allow envi to run.
2. Ensure you downloaded the version for Windows.
3. Restart your computer.

If you see an error while editing:

1. Check if another program has the file open. Close the file in other editors. 
2. Verify you have permission to edit the file in your Windows folder settings.
3. Use the "Refresh" button to reload the file contents from your drive.

## 📋 Best practices for your files

Keep your project folders clean for the best results:

- Name your primary file `.env`.
- Use a separate file format for test data.
- Regularly scan your files to catch deprecated keys. 
- Use the diff tool whenever you pull new updates from a team project.

You might want to keep separate settings for local development and cloud production. Create a profile for each stage. Envi saves these separately. Click the gear icon to switch between configurations. This prevents you from accidentally using local passwords in a live environment.
